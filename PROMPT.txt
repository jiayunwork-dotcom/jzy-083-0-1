光学镀膜实验室在设计增透膜、高反膜时，需要反复计算多层介质膜的光谱响应。目前靠各自的脚本各算一套，参数惯例和偏振处理常常对不齐。我们希望有一个只通过 HTTP 提供计算的薄膜光学核算服务，把特征矩阵法固化成统一口径，供设计与检测环节共用。

计算模型是分层均匀介质的特征矩阵法。调用方给出入射介质与基底的折射率、中间各层的折射率与物理厚度、入射波长以及入射角；服务按每一层构造二阶特征矩阵，把各层矩阵按顺序连乘得到整个膜系的特征矩阵，再由它算出该波长与角度下的反射率、透射率，以及有吸收时的吸收率。每一层的特征矩阵由该层的相位厚度与该层在当前偏振下的等效光学导纳决定，相位厚度取决于折射率、物理厚度、入射角的余弦与波长；等效光学导纳对 s 偏振与 p 偏振各有其固定表达式，两种偏振的导纳公式必须各自独立、不能把一种偏振的导纳误用到另一种上。请以复数矩阵连乘实现，使含吸收（折射率带虚部）的情形也能自然处理。

服务要同时支持单点计算与光谱扫描：单点给定一个波长与角度返回反射率、透射率与吸收率；光谱扫描在一段波长区间上逐点计算，返回反射率随波长变化的点列，供绘制光谱曲线。光谱点列必须由同一套矩阵计算真实产生，不能返回预设的固定形状。

有几条能量与结构关系必须始终成立，请作为正确性基准并用测试锁定：在无吸收（所有折射率为实数）时，任一波长与角度下反射率与透射率之和为一；有吸收时反射率、吸收率与透射率之和为一且吸收率非负；当中间没有膜层时，结果应退化为入射介质与基底之间的单界面菲涅耳反射；一层四分之一波长光学厚度的增透膜，在其设计波长附近的反射率应明显低于无膜时的裸基底；把这层的光学厚度从四分之一波长改到二分之一波长，则设计波长处的增透效果消失、反射率回升；仅把入射角增大到接近掠射，反射率升高。计算相位厚度时务必包含入射角余弦这一因子，否则斜入射下光谱峰位会整体偏移。输入校验要在计算前完成：层厚为负、折射率实部非正、波长非正、入射角不小于九十度等非法输入，返回结构化错误说明。

对外用 JSON 交互，至少提供：一个由膜系、波长与入射角返回反射率、透射率、吸收率的入口；一个由膜系与波段返回反射率光谱点列的入口。服务要能并发处理多路计算请求，各请求的膜系数据与矩阵中间量互不干扰。为便于核对，内置一份玻璃基底上单层四分之一波长增透膜的示范膜系，加载后即可复现「设计波长反射率低于裸基底」这一关系。

技术栈这样定：用 Python 3.12 作为实现语言，Web 服务用 Flask 承载。模块划分要体现清晰的职责分层——复数特征矩阵的构造与连乘、光学导纳及 s/p 偏振处理、单点的反射透射吸收求解、波长光谱扫描、输入合法性校验、以及 HTTP 接口层，各归各的文件，别把矩阵运算和接口代码混在一起。测试请把这几件事锁死：无吸收膜系任意波长下反射率加透射率为一、四分之一波长增透膜在设计波长处反射率明显低于裸基底、无膜时退化为单界面菲涅耳、非法膜系与参数在计算前被拒。交付走容器化，单条命令完成镜像构建与启动、监听 HTTP 端口，运行时基础镜像用 Python 3.12。服务范围就是上面这套薄膜光学计算，仅经 HTTP 对外，不需要任何网页界面，也与滤镜售卖、图片留存这类业务无关。
